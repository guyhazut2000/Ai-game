# Document changes for this release or PR

Follow the **"Document changes"** section of **docs/workflow.md**.

Do the following:

1. **Choose the changelog location** — Use PROJECT_ARCHITECTURE.md Section 13 (Versioning and Changelog), or CHANGELOG.md in the repo root or docs/, whichever the project uses consistently.
2. **Add entries** — Under the current version (or "Unreleased"), add bullets under:
   - **Added** — New features, systems, or capabilities.
   - **Fixed** — Bug fixes and corrections.
   - **Removed** — Deprecated or removed features/APIs.
3. **Commit** — Commit the doc change (e.g. "docs: add X to changelog") or include it in the PR.

Read docs/workflow.md for the exact format and rules.
