# Check branch and repo state

Follow the **"Check branch and repo state"** section of **docs/workflow.md**.

Do the following:

1. Run `git status` and report current branch and any uncommitted files.
2. If there are uncommitted changes, either commit them (with a clear message) or stash them.
3. Run `git pull` (or `git pull --rebase` if that is project policy) so the current branch is up to date.

Report the result (branch name, whether the working tree is clean, and that latest was pulled).
